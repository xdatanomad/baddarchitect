## Post copy

A good AI prompt can produce a great result once. That is not the same as being able to repeat it.

You know the pattern. Friday, you feed the assistant the right notes and get a sharp draft. You save the prompt. A week later the same prompt misses an open issue, repeats a commitment that changed, and leans on a source that has gone stale.

The prompt was fine. It was carrying more than a prompt can hold: which sources are current and allowed, what a good result looks like, what to check, and when to stop.

A saved prompt preserves the words. A personal practice preserves the conditions:

- Ground: start from current, permitted, authoritative sources.
- Generate: visible, repeatable steps you can inspect.
- Verify: an explicit quality gate, then your judgment, before you rely on it.

"Review carefully" is not a method. Name the gate: the field that must be present, the period that must match, the number that must recompute, the claim that must trace to a source.

You do not need a system for this. One page - task, boundary, context, method, review, learning - is enough for one recurring task.

Decision rule: treat an AI interaction as exploration, not a practice, until you can name the recurring task, the allowed context, the expected result, the check it must pass, and the condition under which you will not use it.
